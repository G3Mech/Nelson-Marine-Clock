Tags attach to the boats themselves, so each boat gets one permanent link that stays correct no matter which slip — or the yard — it ends up in later. Search by slip number, boat model, boat name, or customer name, then copy that boat's link into a tag-writing app (e.g. "NFC Tools" on iPhone or Android) to program its tag.

Writing to tags directly from a web page only works on Android Chrome, not iPhone at all — that's why this is copy/paste into a separate app rather than built in here.
